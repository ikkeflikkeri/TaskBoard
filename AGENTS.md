# TaskBoard

A task board API. See `README.md` for setup and run instructions.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `ikkeflikkeri/TaskBoard`, operated with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles map to same-named labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and one `docs/adr/`. See `docs/agents/domain.md`.
